## 目标与约束

- Server 根目录只接受订单号目录，内层第一个 `_` 前为订单号、最后一个 `-` 后为优化编号；无说明时兼容 `订单号_YYYYMMDDHHMMSS`。
- 只发现未处理优化；完成或忽略后不再读取内部文件或比较版本。
- 大板统计提供板材；封边只读取封边汇总，同色累计。工厂单列表按首个横线拆分编号与完整名称。
- App 按工厂单推断正常/返工，允许确认修改；按订单与用途分配材料，总量必须平衡。
- 未出货工厂单五金同内容跳过、不同内容保留或替换；已出货不检查五金。
- 返工补开材料出库单，追加材料与等量消耗，不改原生产/出货状态；不确定外部结果先核对。
- 历史监控范围固定，退出后不重新加入；范围清空在 App 提醒清理旧代码。
- 不覆盖工作树既有修改。真实订单和库存不作为测试夹具。
