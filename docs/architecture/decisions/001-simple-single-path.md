# ADR-001：只保留单一现行路径

状态：现行原则；详细历史说明保留在本 ADR，现行改动以 [AGENTS.md](../../../AGENTS.md) 和 [数据模型](../pp-flowhub-data-model.md) 为准。

## 决定

项目优先维护一条清晰的现行 UI、CLI、工作表和业务路径，不为没有当前价值的旧行为新增长期兼容分支；保留真实数据与现有迁移。结构变化时直接更新现行代码、测试和文档。

## 理由

当前应用只有一个主要用户，且正在快速确定业务流程。兼容分支会增加测试面、路由歧义和维护成本，但不产生当前价值。

## 影响

- 旧决定曾允许开发中直接重建本地数据库，以减少早期 schema 变更成本；该做法会删除真实事实，现已废止。数据库变更必须遵守现有迁移和 [数据模型](../pp-flowhub-data-model.md)。
- 只接受标准 Traveler 工作表名的现行业务约束仍以当前模板和业务规则为准；不要借 ADR 新增兼容别名或重复路径。
- 旧安装或旧状态的处理以当前迁移实现和发布流程为准，不能笼统宣称“不会迁移”。
